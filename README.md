Übersicht

FileChangeDetection ist ein in C geschriebenes Tool zur Erkennung von Datei- und Verzeichnisänderungen. Es eignet sich für Monitoring-, Backup- oder Automatisierungszwecke.

Technische Details

Sprache: C

Systemnah: Direkte Nutzung von Betriebssystem-Funktionen

Fokus:

Traversierung von Verzeichnissen

Vergleich von Dateistatus (Zeitstempel, Größe etc.)

Features

Erkennung von Dateiänderungen

Leichtgewichtig & performant

Modularer Aufbau (traverse, utils, types)

Mögliche Erweiterungen

Echtzeit-Monitoring über OS-spezifische APIs

Logging / Diff-Ausgabe

Rekursive Filter
